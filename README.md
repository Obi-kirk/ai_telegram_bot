# Кузница Северного Ветра — Telegram-бот (тестовый проект)

Демонстрационный Telegram-бот-консультант вымышленного магазина ножей ручной работы «Кузница Северного Ветра». Отвечает на вопросы (RAG + LLM), помогает подобрать нож по описанию, оформляет заказы в корзину.

> ⚠️ **Это тестовый проект.** Магазин и товары вымышленные, заказы не обрабатываются, оплата не принимается. Ответы LLM могут быть неточными — бот не несёт ответственности за их корректность. Полный текст дисклеймера — в боте по команде `/privacy`.

## Возможности

- **LLM-консультант**: вопросы о ножах в свободной форме; ответы строятся на базе знаний (RAG, 11 документов) с учётом истории диалога (последние 6 сообщений).
- **Поиск товара по описанию**: «охотничий нож до 15 тысяч со сталью D2» → подходящие модели со списком и кнопками «+ В корзину».
- **Каталог**: `/catalog` — 8 моделей по категориям (охотничьи, складные, кухонные, выживание) + аксессуары.
- **Корзина**: `/cart` — добавление по артикулу, кнопки `+/−`, очистка, оформление заказа с подтверждением.
- **Заказы**: `/status` — свои заказы; `/order <id> <статус>` и `/orders` (employee+) — управление статусами.
- **Роли**: user / employee / admin (`/setrole`, `/block`, `/unblock`, `/admin_stats`) — внутренние команды защищены декоратором `require_role`.
- **Служебное**: `/about` — о магазине, `/privacy` — политика конфиденциальности, `/help`.

## Стек

Python 3.14 · aiogram 3.x · SQLAlchemy async · asyncpg · PostgreSQL + pgvector · sentence-transformers (all-MiniLM-L6-v2) · OpenRouter (DeepSeek) с fallback на Groq

## Установка и запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# настройте .env (см. ниже)
python -m src.main
```

### .env

```text
TELEGRAM_BOT_TOKEN=токен
DATABASE_URL=postgresql+asyncpg://user:pass@localhost/db
OPENROUTER_API_KEY=ключ
GROQ_API_KEY=ключ              # опционально, fallback
ADMIN_IDS=111,222              # telegram_id админов через запятую
TESTING=1                      # только для тестов (NullPool)
```

БД должна содержать расширение pgvector. Таблицы и RAG-индексы создаются автоматически при старте.

## Тесты

```bash
pytest tests/ -v
```

## Структура

```text
src/
├── handlers/    # команды бота (shop, admin, employee, access, message)
├── services/    # RAG-ответы, корзина, заказы, матчер, история диалога, LLM
├── database/    # модели SQLAlchemy, подключение
├── rag/         # эмбеддинги, векторный поиск
├── utils/       # sanitize, markdown-конвертер, команды бота
└── main.py      # точка входа
data/            # база знаний (txt-документы)
tests/           # pytest
```
